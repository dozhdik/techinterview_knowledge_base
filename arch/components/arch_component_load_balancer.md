# Load Balancer (Балансировщик нагрузки)

## Определение
Load Balancer (балансировщик нагрузки) — компонент распределённой системы, который распределяет входящий сетевой трафик между несколькими серверами (инстансами) для обеспечения высокой доступности, отказоустойчивости и масштабируемости приложения.

## Назначение
- **Распределение нагрузки**: предотвращает перегрузку отдельных серверов, равномерно распределяя запросы.
- **Отказоустойчивость**: автоматически исключает неработающие инстансы из пула, перенаправляя трафик на здоровые.
- **Горизонтальное масштабирование**: позволяет добавлять новые серверы «на лету» без простоя системы.
- **Гибкость развёртывания**: поддерживает blue-green deployments, canary releases и A/B-тестирование.

## Типы балансировщиков

### По уровню OSI-модели
| Тип | Уровень | Примеры | Особенности |
|-----|---------|---------|-------------|
| **Layer 4 (Transport)** | Транспортный (TCP/UDP) | AWS NLB, HAProxy (L4) | Работает с IP:port, не анализирует содержимое запроса, высокая производительность |
| **Layer 7 (Application)** | Прикладной (HTTP/HTTPS) | AWS ALB, Nginx, Envoy | Анализирует заголовки, путь, cookies; поддерживает маршрутизацию по контенту, SSL-терминацию |

### По месту развёртывания
- **Внешний (Internet-facing)**: принимает трафик из публичного интернета.
- **Внутренний (Internal)**: балансирует трафик внутри приватной сети (между микросервисами).

## Алгоритмы балансировки

| Алгоритм | Описание | Когда использовать |
|----------|----------|-------------------|
| **Round Robin** | Запросы по очереди каждому серверу | Однородные серверы, одинаковая нагрузка |
| **Least Connections** | Запрос идёт на сервер с наименьшим числом активных соединений | Разная длительность обработки запросов |
| **IP Hash** | Клиент всегда попадает на один и тот же сервер по хешу его IP | Сессионная привязка (sticky sessions) |
| **Weighted Round Robin** | Серверам назначаются веса; более мощные получают больше трафика | Гетерогенный пул серверов |
| **Geographic** | Маршрутизация по географическому положению клиента | Глобальные приложения, снижение задержки |
