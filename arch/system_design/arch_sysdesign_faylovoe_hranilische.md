# Файловое хранилище

## Задача

Нужно принимать, хранить и отдавать файлы с контролем доступа и восстановлением после сбоев.

## Главное

- Байты размещайте в object storage.
- Метаданные и права храните отдельно.
- Большую загрузку разбивайте на части и проверяйте целостность.

## Как устроено

Байты файлов размещают в объектном хранилище, а метаданные и права — отдельно. Загрузка может идти напрямую по временной ссылке; после завершения сервис подтверждает размер и контрольную сумму.

## Практический пример

Пользователь загружает большой файл частями, затем получает ID объекта. Скачивание проверяет владельца и выдаёт временный URL без проксирования всех байтов через приложение.

## Ограничения

Частично загруженные объекты нужно очищать. Учитывайте пределы размера, проверку типа содержимого, версионирование и восстановление после прерванной передачи.

## Что оценить

Для расчёта ёмкости нужны средний и максимальный размер файла, число загрузок в сутки, срок хранения и доля скачиваний. Разделите стоимость хранения байтов и исходящего трафика; проверьте, как пользователь возобновит прерванную загрузку и увидит её статус.

## На собеседовании

Опишите выдачу временной ссылки и очистку незавершённой загрузки.
