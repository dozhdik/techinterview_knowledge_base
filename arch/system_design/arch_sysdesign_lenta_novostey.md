# Лента новостей

## Задача

Нужно показывать пользователю обновления подписок с приемлемой задержкой при неравномерной популярности авторов.

## Главное

- Храните посты отдельно от списка подписок.
- fan-out при записи ускоряет чтение, но дорог для знаменитостей.
- Курсорная пагинация избегает пропусков при новых постах.

## Как устроено

Сервис получает посты, связи подписки и выдаёт персональную ленту. Для обычных авторов можно заранее разнести ID поста по лентам подписчиков; для очень популярных выгоднее подтянуть их записи при чтении.

## Практический пример

Новый пост автора с сотней подписчиков быстро попадает в подготовленные ленты. Пост знаменитости с миллионами подписчиков обрабатывают отдельно, чтобы одна запись не создала огромный всплеск.

## Ограничения

Определите порядок по времени, дедупликацию и правила удаления поста. Курсор должен сохранять стабильную позицию, когда между страницами появляются новые записи.

## Что оценить

Перед выбором fan-out оцените частоту публикаций, распределение числа подписчиков, допустимую задержку появления поста и объём ленты на пользователя. Отдельно определите, нужен ли точный порядок при одинаковом времени публикации и как удаление поста отражается в уже подготовленных лентах.

## На собеседовании

Объясните гибридную выдачу для обычных авторов и пользователей с миллионами подписчиков.
