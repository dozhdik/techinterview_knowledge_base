# Фильтр Блума Bloom filter

## Определение

Фильтр Блума — вероятностная структура для проверки возможного присутствия ключа.

## Главное

- Отрицательный ответ надёжен при корректной реализации.
- Положительный может быть ложным.
- Удаление требует специальной модификации, например счётчиков.

## Как это работает

Фильтр Блума устанавливает несколько битов для каждого ключа через независимые хеш-функции. Проверка смотрит все соответствующие позиции: отсутствие хотя бы одного бита исключает ключ, все установленные биты дают лишь возможное совпадение.

## Пример

Перед дорогим чтением с диска фильтр может быстро отсечь запрос к ключу, которого точно нет. Положительный ответ всё равно требует проверки в основном хранилище.

## Границы и ошибки

Вероятность ложных срабатываний растёт с заполнением массива битов. Обычный фильтр не поддерживает безопасное удаление отдельного ключа; результат не содержит значение и не перечисляет элементы.

## На собеседовании

Уточните допустимую долю ложных срабатываний и покажите применение перед дорогим чтением.
