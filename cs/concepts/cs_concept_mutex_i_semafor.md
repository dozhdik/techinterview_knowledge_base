# Mutex и семафор

## Определение

Mutex даёт взаимоисключение для критической секции; семафор управляет числом доступных разрешений.

## Главное

- Mutex защищает инвариант общего состояния.
- Семафор ограничивает параллелизм.
- Неверный порядок захвата создаёт deadlock.

## Как это работает

Mutex разрешает вход в критическую секцию одному владельцу; семафор хранит счётчик доступных разрешений и может пропускать несколько операций одновременно. У обоих примитивов важно согласованное освобождение.

## Пример

Для изменения общего баланса используют mutex вокруг проверки и записи. Для пула из пяти соединений семафор с пятью разрешениями ограничит число одновременных пользователей.

## Границы и ошибки

Долгая работа под замком уменьшает параллелизм. Разный порядок захвата нескольких замков создаёт риск deadlock; семафор не заменяет защиту инварианта произвольных данных.

## На собеседовании

Предложите порядок захвата блокировок и объясните, когда достаточно семафора на N ресурсов.
