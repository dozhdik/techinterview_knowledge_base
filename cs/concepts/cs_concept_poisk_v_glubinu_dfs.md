# Поиск в глубину DFS

## Определение

Поиск в глубину (Depth-First Search, DFS) исследует достижимые вершины графа, углубляясь по одной ветви до тех пор, пока есть непосещённые соседи, затем возвращается к предыдущей вершине. Возврат обеспечивают рекурсивный стек вызовов или явно созданный стек.

## Главное

- При списках смежности полный обход занимает O(V + E) времени; набор посещённых вершин и стек могут занимать O(V) памяти.
- Порядок посещения определяется порядком соседей и может отличаться при разных представлениях одного графа.
- Для графа с циклами и повторными путями необходим учёт посещённых вершин.
- DFS помогает проверять достижимость, находить компоненты связности и служит основой некоторых алгоритмов поиска циклов и топологической сортировки.

## Как это работает

В графе A—B, A—C, B—D, C—D один из возможных рекурсивных обходов начинается с A, затем B и D; из D можно попасть в C. После исчерпания соседей алгоритм последовательно возвращается по стеку вызовов. Порядок зависит от порядка списков смежности.

```python
def dfs(graph, start):
    visited = set()
    order = []

    def visit(vertex):
        visited.add(vertex)
        order.append(vertex)
        for neighbour in graph.get(vertex, ()):
            if neighbour not in visited:
                visit(neighbour)

    visit(start)
    return order
```

`graph` отображает вершину в список соседей. Пример возвращает порядок обхода достижимой части, а не расстояния. Рекурсивная глубина может достигать числа вершин; для длинных цепочек в Python нужен явный стек или другая стратегия с учётом ограничения глубины рекурсии.

## Применение

Для проверки достижимости достаточно выяснить, обнаружена ли целевая вершина. В неориентированном графе повторные запуски из непосещённых вершин позволяют выделить компоненты связности. Для ориентированного графа поиск цикла требует различать активные вершины текущего пути и завершённые; одного факта посещения недостаточно.

## Границы и ошибки

- DFS не гарантирует кратчайший путь. В невзвешенном графе для минимального числа рёбер обычно используют BFS.
- Один запуск не охватывает недостижимые вершины. Для полного обхода запускайте DFS из каждой ещё не посещённой вершины.
- В неориентированном графе обратное ребро к родителю само по себе не доказывает цикл; учитывайте направление графа и особенности представления рёбер.
- Не используйте общий набор посещённых вершин без разбора для перечисления всех простых путей: разные задачи требуют разного состояния и отката.

## На собеседовании

Уточните, какой результат нужен — порядок, достижимость, компоненты или цикл, — и направлен ли граф. Проверьте пустую достижимую окрестность, цикл, две ветви с общей вершиной и глубокую цепочку.
