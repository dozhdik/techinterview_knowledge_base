# Поиск в ширину BFS

## Определение

Поиск в ширину (Breadth-First Search, BFS) обходит достижимые вершины графа по неубыванию расстояния от исходной вершины. Он сначала рассматривает соседей старта, затем вершины следующего слоя. Для хранения границы обхода обычно используют очередь FIFO.

## Главное

- В невзвешенном графе расстояние равно минимальному числу рёбер от старта. При одинаковом положительном весе рёбер минимальное число рёбер также даёт путь минимального веса.
- При списках смежности время обхода — O(V + E), дополнительная память — O(V), где V и E относятся к достижимой части графа; для полного обхода по всем компонентам — к графу целиком.
- Вершину отмечают обнаруженной при добавлении в очередь. Это предотвращает повторное добавление и позволяет зафиксировать родителя при первом обнаружении.
- Порядок вершин внутри одного слоя зависит от порядка соседей; кратчайший путь может быть не единственным.

## Как это работает

Пусть рёбра невзвешенного графа: A—B, A—C, B—D, C—D. Начинаем с очереди `[A]` и расстояния A = 0. Извлекаем A и добавляем B и C с расстоянием 1. Затем извлекаем B и добавляем D с расстоянием 2. При обработке C вершина D уже обнаружена, поэтому повторно в очередь не попадает. Один возможный порядок — A, B, C, D; восстановленный путь до D — A → B → D.

```python
from collections import deque


def bfs(graph, start):
    distance = {start: 0}
    parent = {start: None}
    queue = deque([start])
    while queue:
        vertex = queue.popleft()
        for neighbour in graph.get(vertex, ()):
            if neighbour not in distance:
                distance[neighbour] = distance[vertex] + 1
                parent[neighbour] = vertex
                queue.append(neighbour)
    return distance, parent
```

Здесь `graph` — отображение вершины на её соседей. Для неориентированного графа каждое ребро обычно присутствует в обоих списках. `distance` содержит только достижимые вершины, а `parent` позволяет восстановить один из кратчайших путей, двигаясь от цели к старту и затем развернув последовательность. `deque.popleft()` предназначен для эффективного удаления из начала очереди.

## Применение

BFS используют для минимального числа ходов в лабиринте, поиска степени связи в социальной сети и обхода дерева по уровням. В задаче о лабиринте вершинами могут быть проходимые клетки, а рёбрами — разрешённые переходы между соседними клетками.

## Границы и ошибки

- Разные веса рёбер делают обычный BFS неподходящим для общего поиска пути минимального веса. Для неотрицательных весов применяют, например, алгоритм Дейкстры.
- Поиск от одной вершины не посетит недостижимые вершины. Чтобы обойти весь несвязный граф, запускают обход из каждой ещё не посещённой вершины.
- Не путайте «обнаружена» и «извлечена»: поздняя отметка может многократно поставить вершину в очередь.
- Для очень широких графов очередь может содержать большую часть слоя и занимать значительную память.

## На собеседовании

Уточните направленность и веса рёбер, состав входа и требуемый результат: порядок, расстояние или сам путь. Назовите сложность относительно представления графа и проверьте старт без соседей, цикл, недостижимую цель и несколько равных кратчайших путей.
