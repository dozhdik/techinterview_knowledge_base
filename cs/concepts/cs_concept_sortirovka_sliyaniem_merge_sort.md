# Сортировка слиянием Merge Sort

## Определение

Merge Sort делит последовательность пополам, сортирует части и сливает их.

## Главное

- Время O(n log n) в худшем случае.
- Стандартная реализация для массива требует O(n) дополнительной памяти.
- Слияние может сохранять порядок равных элементов.

## Как это работает

Рекурсивное деление создаёт уровни по O(log n); на каждом уровне все элементы участвуют в слиянии за O(n). Для массива обычно выделяют вспомогательный буфер.

## Пример

При сортировке записей по возрасту стабильное слияние сохраняет исходный порядок людей одного возраста, если при равенстве первым берут элемент левой части.

## Границы и ошибки

Стабильность зависит от реализации сравнения при равенстве. Не заявляйте O(1) дополнительной памяти для стандартной реализации над массивом.

## На собеседовании

Сравните гарантированную оценку с Quick Sort и объясните цену дополнительного буфера.
