# Связный список

## Определение

Связный список состоит из узлов со ссылками на следующие элементы; двусвязный список хранит ссылку и на предыдущий.

## Главное

- Доступ к i-му узлу стоит O(n).
- Вставка после известного узла стоит O(1).
- Указатели требуют дополнительной памяти.

## Как это работает

Узел односвязного списка хранит значение и ссылку на следующий узел. Для вставки после найденного узла меняют несколько ссылок; для доступа по номеру приходится идти от головы последовательно.

## Пример

Чтобы удалить следующий узел, достаточно соединить текущий с узлом после удаляемого. Если известен только ключ, сначала нужен линейный поиск; у двусвязного списка удаление известного узла проще за счёт ссылки назад.

## Границы и ошибки

Учитывайте пустой список, удаление головы и хвоста. Сравнение с массивом зависит от того, известна ли позиция: O(1) вставки не включает поиск места.

## На собеседовании

Уточните, известен ли узел для удаления: без него сначала нужен поиск.
