# Топологическая сортировка

## Определение

Топологическая сортировка — это линейное упорядочивание вершин ориентированного ациклического графа (DAG), при котором для каждого ребра `u → v` вершина `u` идёт раньше `v`. Такая сортировка существует только для графов без циклов.

## Суть концепции

Топологическая сортировка нужна там, где есть зависимости между задачами, объектами или шагами, и требуется найти корректный порядок выполнения. Если одна вершина зависит от другой, то зависимость должна быть обработана раньше. Поэтому топологическая сортировка — это не просто “ещё один обход графа”, а способ восстановить допустимую последовательность при наличии частичного порядка.

Ключевое условие — граф должен быть ориентированным и ациклическим. Если в графе есть цикл, корректного порядка не существует: каждая вершина в цикле требует, чтобы её кто-то предшествовал, но при этом сама зависит от следующей. Это делает задачу неразрешимой в терминах линейного порядка.

Есть два классических способа выполнить топологическую сортировку:
- алгоритм Кана через входные степени (`in-degree`);
- DFS-подход с добавлением вершины в ответ после обработки всех потомков.

Алгоритм Кана работает так: мы находим все вершины с нулевой входной степенью, кладём их в очередь и по одной извлекаем, уменьшая входные степени их соседей. Когда у соседа входная степень становится нулевой, он тоже становится готовым к обработке. Если в конце удалось обработать все вершины, граф был DAG. Если нет — в графе есть цикл.

DFS-подход использует идею postorder: сначала углубляемся во все достижимые вершины, а потом добавляем текущую вершину в результат. Если развернуть этот результат, получится топологический порядок. Для обнаружения цикла обычно используют состояния вершин: `unvisited`, `visiting`, `visited`.

На собеседовании важно понимать не только как написать код, но и как распознать задачу на topological sort. Типичные формулировки:
- “есть зависимости”;
- “нужно определить порядок прохождения курсов”;
- “нужно восстановить корректную последовательность задач”;
- “нужно проверить, возможно ли выполнить всё”.

## Ключевые характеристики

- **Применима только к**: ориентированному ациклическому графу (DAG)
- **Результат**: один из возможных корректных линейных порядков
- **Если есть цикл**: топологическая сортировка невозможна
- **Основные подходы**:
    - BFS / Kahn’s Algorithm
    - DFS + postorder
- **Проверка наличия цикла**:
    - по числу обработанных вершин в алгоритме Кана;
    - по обратному ребру в DFS
- **Временная сложность**: `O(V + E)`
- **Пространственная сложность**: `O(V + E)` для хранения графа и служебных структур

## Визуальное представление

```text
Граф зависимостей:

A → C
B → C
C → D
C → E

Возможный топологический порядок:
A, B, C, D, E

или
B, A, C, E, D

Оба варианта корректны, потому что:
- A и B идут раньше C
- C идёт раньше D и E
```
