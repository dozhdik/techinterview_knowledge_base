# Fast and Slow Pointers

## Суть паттерна

Fast and Slow Pointers — это паттерн, в котором два указателя движутся по структуре с разной скоростью, чтобы извлечь информацию о её форме или свойствах без дополнительной памяти. Чаще всего он применяется к связным спискам, но может использоваться и в массивах, если переход к следующему состоянию определяется функцией.

Классический пример — обнаружение цикла в linked list с помощью алгоритма Флойда. Если один указатель идёт по одному шагу, а второй по два, то при наличии цикла они рано или поздно встретятся. Если цикла нет, быстрый указатель дойдёт до конца структуры.

Паттерн полезен там, где нужно:
- определить наличие цикла;
- найти середину списка;
- найти точку входа в цикл;
- сравнить половины последовательности;
- работать с последовательностью в `O(1)` памяти.

Сильная сторона паттерна — он часто даёт решение лучше, чем использование hash set или дополнительного массива посещённых элементов. Но он работает не везде. Если задача не сводится к движению по последовательности или состояниям с разной скоростью, этот паттерн будет натяжкой.

## Когда применять

Fast and Slow Pointers стоит рассматривать, если в задаче есть такие признаки:

- есть линейная структура: связный список, массив, последовательность состояний;
- нужно понять, есть ли цикл;
- нужно найти середину структуры;
- нужно разбить последовательность на две части;
- важно решить задачу без дополнительной памяти;
- можно определить переход “следующего элемента”.

### Типичные сигналы в условии

- “определить, содержит ли список цикл”;
- “найти средний элемент linked list”;
- “найти начало цикла”;
- “сравнить первую и вторую половины списка”;
- “решить в `O(1)` дополнительной памяти”.

### Когда паттерн не подходит

- структура не линейная;
- нужен полный перебор или глобальная оптимизация;
- нет понятия “двигаться дальше”;
- проще и надёжнее использовать другой паттерн, например hash set.

## Шаблон решения

```python
def fast_slow_pattern(head):
    slow = head
    fast = head

    while fast is not None and fast.next is not None:
        slow = slow.next
        fast = fast.next.next

        if slow == fast:
            return True

    return False
