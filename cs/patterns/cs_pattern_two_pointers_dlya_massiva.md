# Two Pointers для массива

## Идея паттерна

Два указателя движутся по массиву с разных концов или в одном направлении, сокращая повторную работу.

## Главное

- В отсортированном массиве сумма сравнивается с целью.
- Инвариант определяет безопасный сдвиг.
- Время часто O(n), если каждый указатель движется монотонно.

## Как это работает

Два индекса движутся по массиву по заранее заданному инварианту. Часто один указывает на начало, другой на конец отсортированного диапазона; после сравнения можно отбросить часть вариантов без вложенного перебора.

## Пример

В отсортированном массиве для суммы target сравнивают a[left]+a[right]. Если сумма мала, увеличивают left; если велика, уменьшают right.

## Границы и ошибки

Не переносите этот переход на неотсортированный массив без доказательства. Для удаления дубликатов оба указателя могут идти в одном направлении, но смысл их позиций другой.

## На собеседовании

Объясните, почему сортировка входа может изменить исходные индексы.
