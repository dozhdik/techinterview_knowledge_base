# Merge Intervals

## Условие

Дан массив интервалов `intervals`, где каждый интервал задан как `[start, end]`. Нужно объединить все пересекающиеся интервалы и вернуть массив непересекающихся интервалов, покрывающих тот же диапазон.

Два интервала считаются пересекающимися, если следующий начинается не позже, чем заканчивается текущий объединённый интервал.

## Примеры

### Пример 1
- **Вход**: `intervals = [[1,3],[2,6],[8,10],[15,18]]`
- **Выход**: `[[1,6],[8,10],[15,18]]`
- **Объяснение**: интервалы `[1,3]` и `[2,6]` пересекаются, поэтому объединяются в `[1,6]`.

### Пример 2
- **Вход**: `intervals = [[1,4],[4,5]]`
- **Выход**: `[[1,5]]`
- **Объяснение**: интервал `[4,5]` примыкает к `[1,4]` по границе и тоже объединяется.

### Пример 3
- **Вход**: `intervals = [[1,4],[5,6]]`
- **Выход**: `[[1,4],[5,6]]`
- **Объяснение**: интервалы не пересекаются, поэтому остаются как есть.

## Ограничения

- `1 <= len(intervals) <= 10^4`
- `intervals[i].length == 2`
- `0 <= start <= end <= 10^4`

## Уточняющие вопросы кандидата

1. **Считаются ли интервалы с общей границей пересекающимися?**  
   В классической версии да: `[1,4]` и `[4,5]` объединяются.

2. **Нужно ли сохранять исходный порядок интервалов?**  
   Обычно нет, потому что стандартное решение начинается с сортировки.

## Подход к решению

### Шаг 1: Brute Force
- **Идея**: многократно сравнивать все пары интервалов и сливать пересекающиеся, пока больше нечего сливать.
- **Сложность**: до `O(n^2)` и хуже в неаккуратных реализациях.
- **Почему не оптимально**: слишком много повторных сравнений и лишних проходов.

### Шаг 2: Оптимизация
- **Паттерн**: sorting + greedy merge
- **Ключевое наблюдение**: если отсортировать интервалы по началу, то все потенциальные пересечения для текущего интервала будут идти подряд.
- **Идея**: сортируем интервалы по `start`, затем идём слева направо. Если текущий интервал пересекается с последним в ответе, расширяем правую границу. Если не пересекается — начинаем новый интервал.

## Оптимальное решение

```python
def solution(intervals: list[list[int]]) -> list[list[int]]:
    if not intervals:
        return []

    intervals.sort(key=lambda x: x[0])
    merged = [intervals[0][:]]

    for start, end in intervals[1:]:
        last = merged[-1]

        if start <= last[1]:
            last[1] = max(last[1], end)
        else:
            merged.append([start, end])

    return merged
