# Valid Parentheses

## Условие

Дана строка `s`, состоящая только из символов `'('`, `')'`, `'['`, `']'`, `'{'`, `'}'`. Нужно определить, является ли строка корректной скобочной последовательностью.

Строка считается корректной, если:
- каждая открывающая скобка закрывается скобкой того же типа;
- скобки закрываются в правильном порядке;
- у каждой закрывающей скобки есть соответствующая открывающая до неё.

## Примеры

### Пример 1
- **Вход**: `s = "()"`
- **Выход**: `true`
- **Объяснение**: одна пара круглых скобок открывается и закрывается корректно.

### Пример 2
- **Вход**: `s = "()[]{}"`
- **Выход**: `true`
- **Объяснение**: несколько корректных пар идут подряд и не нарушают порядок вложенности.

### Пример 3
- **Вход**: `s = "(]"`
- **Выход**: `false`
- **Объяснение**: открыта круглая скобка, но закрыта квадратная.

### Пример 4
- **Вход**: `s = "([)]"`
- **Выход**: `false`
- **Объяснение**: типы скобок по отдельности присутствуют, но порядок вложенности нарушен.

### Пример 5
- **Вход**: `s = "{[]}"`
- **Выход**: `true`
- **Объяснение**: скобки вложены корректно.

## Ограничения

- `1 <= len(s) <= 10^4`
- `s[i]` — один из символов: `'('`, `')'`, `'['`, `']'`, `'{'`, `'}'`

## Уточняющие вопросы кандидата

1. **Может ли строка быть пустой?**  
   В разных формулировках задачи да. Обычно пустая строка считается корректной.

2. **Гарантировано ли, что во входе только скобки?**  
   В классической версии да. Это важно, потому что иначе нужно отдельно обсудить поведение на других символах.

## Подход к решению

### Шаг 1: Brute Force
- **Идея**: repeatedly находить и удалять из строки подстроки `"()"`, `"[]"`, `"{}"`, пока это возможно.
- **Сложность**: `O(n^2)` время, `O(n)` память в зависимости от реализации.
- **Почему не оптимально**: требует многократных проходов по строке и плохо масштабируется.

### Шаг 2: Оптимизация
- **Паттерн**: stack
- **Ключевое наблюдение**: закрывающая скобка всегда должна сопоставляться с последней ещё не закрытой открывающей скобкой.
- **Идея**: идём слева направо. Открывающие скобки кладём в стек. При встрече закрывающей проверяем, что стек не пуст и верхушка стека — соответствующая открывающая скобка. Если нет — строка невалидна. В конце стек должен быть пуст.

## Оптимальное решение

```python
def solution(s: str) -> bool:
    pairs = {
        ')': '(',
        ']': '[',
        '}': '{',
    }

    stack = []

    for ch in s:
        if ch in '([{':
            stack.append(ch)
        else:
            if not stack:
                return False
            if stack[-1] != pairs[ch]:
                return False
            stack.pop()

    return len(stack) == 0
