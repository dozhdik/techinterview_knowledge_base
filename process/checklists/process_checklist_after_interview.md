# Чек-лист после технического собеседования

## Сразу после интервью (0-15 минут)

- [ ] Записать впечатления пока свежо: что прошло хорошо, что вызвало трудности
- [ ] Отметить вопросы, на которые ответил неуверенно
- [ ] Зафиксировать фидбек интервьюера (если был)
- [ ] Сохранить имена интервьюеров для последующего thank-you письма
- [ ] Сделать перерыв: прогулка, вода, дыхательные упражнения

## В тот же день (1-4 часа)

- [ ] Проанализировать технические задачи:
  - [ ] Какие решения были оптимальными?
  - [ ] Где можно было улучшить подход?
  - [ ] Какие темы нужно повторить?
- [ ] Пересмотреть behavioral-ответы:
  - [ ] Соответствовали ли они структуре STAR?
  - [ ] Были ли конкретные метрики в результатах?
- [ ] Составить список тем для повторения перед следующими интервью

## Благодарственное письмо (24 часа)

- [ ] Отправить thank-you email рекрутеру/интервьюеру:
  - Поблагодарить за время и возможность
  - Кратко отметить, что понравилось в процессе
  - Подтвердить интерес к позиции
  - Упомянуть 1-2 момента из интервью для персонализации

## Если был отказ

- [ ] Запросить фидбек (если не предоставили автоматически)
- [ ] Проанализировать полученный фидбек без самокритики
- [ ] Выделить 1-2 ключевые зоны роста
- [ ] Составить план работы над ними
- [ ] Не принимать отказ на личный счёт
- [ ] Обновить план подготовки с учётом нового опыта
- [ ] Продолжать подавать заявки

## Если был оффер

- [ ] Поблагодарить и запросить детали в письменном виде
- [ ] Внимательно изучить компенсационный пакет:
  - [ ] Base salary
  - [ ] Bonus structure
  - [ ] Equity/RSU (вестинг, цена, условия)
  - [ ] Benefits (медицина, отпуск, обучение)
- [ ] Сравнить с рыночными данными (Levels.fyi, Glassdoor)
- [ ] Подготовить вопросы по условиям
- [ ] Принять решение в согласованные сроки
- [ ] При необходимости — провести negotiation

## Долгосрочная рефлексия (неделя после)

- [ ] Обновить личный «банк историй» для behavioral-вопросов
- [ ] Добавить новые технические темы в план обучения
- [ ] Отметить прогресс: что стало получаться лучше
- [ ] Запланировать следующие моки или подачу заявок
- [ ] Отпраздновать этап (независимо от результата!)
