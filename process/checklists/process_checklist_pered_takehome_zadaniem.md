# Перед take-home заданием

## Цель проверки

Чек-лист позволяет уточнить критерии до начала домашнего задания.

## Главное

- Проверьте срок, формат сдачи и ограничения.
- Оцените минимально полный объём.
- Запланируйте тесты и инструкции запуска.

## Как применять

Перед началом зафиксируйте требования, время и критерии оценки. Сделайте работающий минимум, затем проверьте тесты, запуск по README, структуру коммитов и объяснение компромиссов.

## Пример

Для небольшого API добавьте инструкцию запуска, примеры запросов, обработку ошибок и несколько проверок важного поведения.

## Что проверить

Не тратьте весь срок на необязательную архитектуру. Если часть не успели, явно перечислите ограничения и следующий шаг вместо маскировки недоделки.

## На собеседовании

Если условие неоднозначно, зафиксируйте своё допущение в README решения.
