# Проверка портфолио проектов

## Цель проверки

Портфолио должно показывать завершённую работу и личный вклад.

## Главное

- Для каждого проекта подготовьте цель, решение и результат.
- Уберите неработающие ссылки.
- Проверьте отсутствие ключей и закрытых данных.

## Как применять

Для каждого проекта укажите задачу, свою роль, ключевое решение, измеримый результат и ссылку на доступный артефакт. Проверьте, что описание можно объяснить без раскрытия закрытых данных.

## Пример

Вместо «создал микросервис» напишите, какую проблему он решил, как проверяли задержку и какую часть системы вы реализовали лично.

## Что проверить

Ссылка на неработающий репозиторий или демо ухудшает впечатление. Не приписывайте себе чужие решения; подготовьте объяснение альтернатив и ограничений.

## На собеседовании

Выберите два проекта, которые отвечают требованиям вакансии.
