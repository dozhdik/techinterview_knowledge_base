# Проверка резюме под вакансию

## Цель проверки

Резюме стоит проверить на соответствие конкретной роли до отклика.

## Главное

- Укажите технологии, которыми реально владеете.
- Покажите достижения, а не только обязанности.
- Исправьте даты и ссылки.

## Как применять

Сопоставьте требования вакансии с реальным опытом и вынесите наиболее релевантные достижения выше. Формулируйте результат через действие, масштаб и эффект, сохраняя правдивость.

## Пример

Для backend-вакансии уместно показать работу с транзакциями, нагрузкой и API раньше второстепенного опыта с интерфейсами.

## Что проверить

Не добавляйте технологии, которые не сможете обсудить. Проверьте даты, названия, контакты и одинаковое написание ключевых терминов.

## На собеседовании

Для каждого пункта приготовьте короткое техническое объяснение.
