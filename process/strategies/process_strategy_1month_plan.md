# План подготовки к собеседованию за 1 месяц

## Для кого этот план
- Кандидаты уровня Junior / начинающие Middle
- Есть базовые знания алгоритмов и структур данных
- Цель: пройти собеседование в продукт-компанию или аутсорс

## Принципы плана
- **Фокус на практике**: 70% времени — решение задач, 30% — теория
- **Spaced repetition**: повторение тем через 1, 3, 7 дней
- **Mock interviews**: минимум 2 пробных собеседования
- **Отслеживание прогресса**: вести журнал решённых задач

## Неделя 1: Фундамент

**Цель:** Повторить базовые структуры данных и паттерны

| День | Тема | Практика |
|------|------|----------|
| 1 | Arrays & Strings | 5 задач Easy на LeetCode |
| 2 | Hash Tables | 5 задач Easy, понять принцип работы |
| 3 | Two Pointers паттерн | 3 задачи на паттерн |
| 4 | Sliding Window паттерн | 3 задачи на паттерн |
| 5 | Binary Search | 4 задачи, понять условия применения |
| 6 | Повторение недели 1 | Решить 2 задачи из каждого дня |
| 7 | Отдых + лёгкое повторение | Прочитать 2 карточки по коммуникации |

**Результат недели:** Уверенно решаешь задачи уровня Easy, понимаешь 4 ключевых паттерна.

## Неделя 2: Углубление

**Цель:** Освоить задачи уровня Medium и базовые алгоритмы

| День | Тема | Практика |
|------|------|----------|
| 8 | Linked Lists | 4 задачи (reverse, cycle, merge) |
| 9 | Trees: BFS/DFS | 4 задачи на обход деревьев |
| 10 | Stacks & Queues | 3 задачи, понять применение |
| 11 | Recursion basics | 3 задачи, научиться писать рекурсию |
| 12 | Sorting & Searching | Повторить quicksort, mergesort, бинарный поиск |
| 13 | Повторение недели 2 | 2 задачи из каждой темы |
| 14 | Mock interview #1 | Пройти пробное собеседование (45 мин) |

**Результат недели:** Решаешь задачи Medium с подсказками, понимаешь базовые алгоритмы.

## Неделя 3: Behavioral + System Design basics

**Цель:** Подготовиться к нетехническим этапам и базовому системному дизайну

| День | Тема | Практика |
|------|------|----------|
| 15 | Метод STAR | Подготовить 3 истории по STAR |
| 16 | Tell Me About Yourself | Написать и отрепетировать самопрезентацию |
| 17 | Conflict / Failure вопросы | Подготовить по 1 истории на каждый тип |
| 18 | System Design: основы | Изучить фреймворк решения, разобрать 1 задачу |
| 19 | Capacity estimation | Потренировать back-of-the-envelope расчёты |
| 20 | Повторение behavioral | Проговорить все истории вслух |
| 21 | Mock interview #2 | Полное пробное собеседование (coding + behavioral) |

**Результат недели:** Готов к behavioral-этапу, понимаешь структуру system design интервью.

## Неделя 4: Финальная подготовка

**Цель:** Закрепить знания, проработать слабые места, настроиться

| День | Тема | Практика |
|------|------|----------|
| 22 | Слабые места | Решить 3 задачи по темам, где были ошибки |
| 23 | Edge cases & тестирование | Пройти 3 задачи с фокусом на тестирование |
| 24 | Тайминг и коммуникация | Решать задачи с таймером, объяснять вслух |
| 25 | Повторение ключевых паттернов | Пройти шпаргалки по паттернам |
| 26 | Подготовка к компании | Изучить процесс собеседования в целевой компании |
| 27 | Лёгкое повторение + отдых | Не решать новые задачи, только повторение |
| 28 | День перед собеседованием | Проверить технику, подготовить вопросы, выспаться |

**Результат недели:** Уверен, структурирован, готов к собеседованию.

## Ежедневный ритуал (30-60 минут)

1. **Разминка (5 мин):** 1 лёгкая задача на повторение
2. **Основная практика (30-40 мин):** 1-2 задачи по теме дня
3. **Анализ (10 мин):** Записать, что получилось / не получилось
4. **Повторение (5 мин):** Проговорить 1 behavioral-историю

## Чек-лист готовности к собеседованию

- [ ] Решил 50+ задач (30 Easy, 20 Medium)
- [ ] Знаю 5+ паттернов и когда их применять
- [ ] Подготовил 3-5 behavioral-историй по STAR
- [ ] Отрепетировал самопрезентацию (2-3 минуты)
- [ ] Прошёл минимум 2 mock interview
- [ ] Изучил процесс в целевой компании
- [ ] Подготовил 3-5 вопросов интервьюеру
- [ ] Проверил технику и среду для онлайн-интервью

## Если времени меньше 1 месяца

**2 недели:** Сфокусируйся на неделях 1 и 4 + 1 mock interview
**1 неделя:** Только ключевые паттерны (Two Pointers, Sliding Window, Hash) + behavioral-подготовка

## Если времени больше 1 месяца

**Добавь:**
- Глубокое изучение динамического программирования
- Больше задач уровня Medium/Hard
- Дополнительные mock interviews (1 в неделю)
- Изучение специфичных тем под целевую компанию
